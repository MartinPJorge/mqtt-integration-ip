# VNX scenario to integrate MQTT alert system with an IP network
This repository contains the instructions and script to deploy a VNX scenario of an IP network that connects: broker, subscriber and publisher of an MQTT scenario reporting vital signs' metrics.
Follow the instructions in `enunciado/main.pdf` to run the script that sets up the VNX IP scenario.

This repository is part of the teaching sessions of the Networking course in the Bsc. of Biomedical Engineering @UPM.
